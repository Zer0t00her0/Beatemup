# AI Sprite Studio

Personal sprite animation generator using OpenAI image editing.

## What it does
Upload a character image, select an animation (Idle, Walk, Run, Punch, Kick, Jump, Hit, Knockdown, Victory), choose frame count and FPS, then generate and preview frames. Regenerate individual frames and export a sprite sheet.

## Running locally
1. Install Python 3.10+.
2. Copy `.env.example` to `.env` and insert your OpenAI API key.
3. Double-click `start.command` on macOS.
4. Open http://127.0.0.1:8765

**Important:** This is a local development application, not a published website. Running it on GitHub alone will not host the AI backend. For a one-link browser experience, a secured server deployment and OpenAI API secret are required.

API usage is separately billed. Frames are generated by individual image edit requests; consistent anatomy and seamless animation are not guaranteed.

Never commit `.env` or expose the backend publicly without authentication.
